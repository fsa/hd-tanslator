# Text Translator

Веб-приложение для перевода текстов. Главная — выбор квестов, редактор — полноэкранный split-view с навигацией по файлам квеста.

## Технологии

- Astro 7 (SSR) + React islands
- TypeScript
- Bootstrap 5 (react-bootstrap)
- SQLite (better-sqlite3)

## Структура файлов

Файлы имеют формат: `[Персонаж].[Подраздел].[Квест]_[ID]_orig.txt`

- `LYRA.4.20_12_orig.txt` — оригинал
- `LYRA.4.20_12.txt` — перевод

## Маршруты

- `/` — главное меню
- `/quests` — список квестов
- `/editor/[quest]` — редактор квеста
- `/settings` — настройки

## Настройки

Пути к файлам и API-ключи настраиваются через `/settings` или через переменные окружения.

### Переменные окружения

| Переменная | Описание | Обязательная |
|---|---|---|
| `ORIGINALS_DIR` | Путь к папке с оригиналами (`*_orig.txt`) | Да |
| `TRANSLATIONS_DIR` | Путь к папке с переводами (`*.txt`) | Да |
| `OPENROUTER_API_KEY` | Ключ API OpenRouter (для будущего использования) | Нет |
| `DB_PATH` | Путь к файлу SQLite БД (по умолч. `./data/translator.db`) | Нет |

Разрешены как абсолютные пути, так и относительные.

### Файлы .env

Проект использует стандартный механизм Astro для загрузки переменных окружения (приоритет: от меньшего к большему):

1. **`.env`** — шаблон с комментариями, все переменные закомментированы. **Добавлен в репозиторий.**
2. **`.env.local`** — локальные настройки и секреты. **Не добавлять в репозиторий** (в `.gitignore`).
3. **`.env.development` / `.env.production`** — для разных режимов сборки (опционально).

Порядок загрузки (более поздние перезаписывают ранние): `.env` → `.env.local` → `.env.development` (при `astro dev`) / `.env.production` (при `astro build`).

**Рекомендация:** скопируйте `.env` в `.env.local` и заполните свои пути и ключи:

```sh
cp .env .env.local
# затем отредактируйте .env.local
```

Подробнее: https://docs.astro.build/en/guides/environment-variables/
