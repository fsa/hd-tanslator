## File Format

The source uses a simple GameScript format.

### Character Label Lines

A line in square brackets identifies the speaker or narration:

[NAME]
[NAME_emotion]

Examples:
[ES]
[LYRA_smile]
[MAIN]
[ES_JOURNAL]

Character label lines MUST be returned exactly unchanged.

Do not translate, modify, normalize, or remove character labels.

### Separator Lines

A line containing exactly:

----

MUST be returned exactly unchanged.

### Dialogue and Description Lines

All other lines are translatable text.

These may contain special constructs that MUST be preserved.

#### {NAME} Placeholders

Examples:

{LYRA}
{HELENA}
{GUEST}
{MAIN}
{LETHE}

Placeholders in curly braces MUST remain exactly unchanged.

Do not translate or modify their contents.

#### Asterisk Actions

Text inside asterisks describes an action, sound, or reaction.

Examples:

*sighs*
*blushes*
*nods*
*sniff* *giggle*

The asterisks MUST remain exactly where they are, but the text inside them MUST be translated naturally.

#### Formatting Tags

Preserve all formatting tags exactly:

<b>...</b>
<i>...</i>
<u>...</u>
<s>...</s>
<size=...>...</size>
<color=...>...</color>
<mark=...>...</mark>
<align=...>...</align>

Translate only the text inside the tags.

Do not change tag names, attributes, or values.

#### Special Markers

Markers such as:

<think>...</think>

must preserve their syntax exactly.

Translate the text contained inside them when appropriate.

#### | Operator

The `|` character separates alternative text variants.

Example:

Hello | Hi | Hey there

Preserve the `|` character and translate every alternative independently.

Do not merge alternatives or remove them.

## Important Localization Principle

Do NOT translate mechanically word by word.

The result should sound like natural Russian spoken by the specific character.

For example:

- "Speaking of the devil." should normally become a natural Russian equivalent such as "Лёгок на помине.", not a literal translation.
- "You got your ass beat." should use a natural Russian vulgar expression rather than literally translating "ass".
- A joke based on an English idiom should be recreated in Russian when possible.
- A cultural reference should retain its recognizable meaning and tone.
- German words or expressions deliberately used by a character should generally be preserved or transliterated when they function as a nickname, catchphrase, or recurring joke.

When translating a joke, insult, idiom, or reference, ask yourself:

"What would a Russian-speaking character naturally say here while producing the same effect?"

Use that answer instead of a literal word-for-word translation.

## Character Voice

Character voice is more important than literal wording.

Consider:
- age
- personality
- confidence
- intelligence
- social status
- relationship with the other character
- emotional state
- previous events in the story
- whether the character is joking, insulting, flirting, threatening, nervous, embarrassed, etc.

If a character is sarcastic, keep the sarcasm.
If a character is vulgar, keep the vulgarity.
If a character is shy, keep the hesitation.
If a character speaks in a deliberately strange way, preserve that strangeness.
