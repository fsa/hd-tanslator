## Game Context

This is a visual novel / dating sim game. Almost all characters are girls or women. The male characters are only: MAIN (protagonist), UNCLE, SIS_DAD. NARR is the narrator (neutral). ES_JOURNAL (or ESJOURNAL with minor variations) is narration from ES's perspective.

## File Format (GameScript)

The text comes from a game script file. Each line is one of three types:

### Type 1: Character Label Lines
Format: `[NAME]` or `[NAME_emotion]`

A line in square brackets indicates which character is speaking, optionally with an emotion suffix (`_emotion`). The line after it is that character's dialogue with the specified emotion.

- `[MAIN]` — main character (male)
- `[NARR]` — narrator
- `[LYRA]` — character LYRA (no emotion)
- `[LYRA_smile]` — character LYRA with smile emotion
- `[OPTION]` — dialogue choice option
- `[ES_JOURNAL]` / `[ESJOURNAL]` — narration from ES's perspective

### Type 2: Separator Lines
Format: `----` (exactly 4 hyphens)

Separates different game screens / scenes.

### Type 3: Dialogue / Description Lines
Regular text lines that may contain the following constructs which must NOT be translated:

#### {NAME} Placeholders
Character name references in curly braces. These are replaced with the character's actual name in-game. Example: `{LYRA}`, `{FARM}`, `{MAIN}`, `{LETHE}`

#### Asterisk Actions
Text wrapped in `*asterisks*` — this is a character action or reaction (e.g. `*sighs*`, `*blushes*`, `*looks away*`). It describes what the character is doing, not dialogue. This text MUST be translated.

#### HTML-like Formatting Tags
- `<b>...</b>` — bold
- `<i>...</i>` — italic
- `<u>...</u>` — underline
- `<s>...</s>` — strikethrough
- `<size=...>...</size>` — font size
- `<color=...>...</color>` — text color
- `<mark=...>...</mark>` — highlight
- `<align=...>...</align>` — alignment
- `thinking...` and `response` — character thoughts (displayed specially)

#### | (OR) Operator
The `|` symbol separates alternative variants. The game randomly picks one.
Example: `Hello | Hi | Hey there`

## Translation Rules

1. Preserve ALL markup tags exactly as they are (e.g. <b>, <i>, <color=...>, etc.)
2. Preserve ALL {NAME} placeholders exactly as they are
3. Preserve the | (OR) operator and all alternatives separated by it
4. Preserve ALL "thinking..." and "response" markers exactly
5. Do NOT translate character names or placeholders
6. Keep the original line structure — one line per translation
7. Maintain the tone and style appropriate for game dialogue
8. Translate naturally, as if the character is speaking in the target language
9. Character label lines ([NAME]) and separator lines (----) must be returned unchanged
10. Only translate dialogue and description lines (Type 3)
11. Use feminine gender forms when translating dialogue for female characters (most of them)
12. Use masculine gender forms only for MAIN, UNCLE, SIS_DAD
