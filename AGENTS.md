# Text Translator

Веб-приложение для перевода текстов. Главная — выбор квестов, редактор — полноэкранный split-view с навигацией по файлам квеста.

## Технологии

- Astro 7 (SSR) + React islands
- TypeScript
- Bootstrap 5 (react-bootstrap)
- SQLite (better-sqlite3)

## Структура файлов (имена)

Файлы имеют формат: `[Персонаж].[Подраздел].[Квест]_[ID]_orig.txt`

- `LYRA.4.20_12_orig.txt` — оригинал
- `LYRA.4.20_12.txt` — перевод

Квесты группируются по `Персонаж.Подраздел.Квест` (например `LYRA.4.20`).

Регулярка для парсинга: `/^([A-Za-z0-9]+)\.(\d+)\.(\d+)_(\d+)_orig\.txt$/`

## Внутренний формат файлов (GameScript)

Файлы (оригинал и перевод) — это простые текстовые файлы. Каждая строка относится к одному из трёх типов.

### Тип 1: Строка-заголовок (метка персонажа)

Формат: `[NAME]` или `[NAME_emotion]`

Строка, которая указывает на имя персонажа и опционально его эмоцию. В строке больше ничего не должно быть — лишние символы считаются ошибкой.

Примеры:
- `[MAIN]` — главный герой
- `[NARR]` — нарратор
- `[LYRA]` — персонаж LYRA без эмоции
- `[LYRA_smile]` — персонаж LYRA с эмоцией smile
- `[FARM_smile]` — персонаж FARM с эмоцией smile
- `[OPTION]` — вариант выбора

Специальные метки: `MAIN`, `NARR`, `OPTION`.

### Тип 2: Строка-разделитель

Формат: `----` (ровно 4 дефиса)

Разделяет сцены или логические блоки. В строке не должно быть ничего, кроме 4 дефисов — лишние символы считаются ошибкой.

### Тип 3: Строка текста (реплика / описание)

Обычный текст строки. Внутри строки могут встречаться следующие конструкции, которые **не нужно переводить**:

#### Подстановки `{NAME}`

Вставка имени персонажа из настроек игры. Внутри `{}` — только имя персонажа, без эмоции.

Пример: `{LYRA}`, `{FARM}`, `{MAIN}`, `{LETHE}`

#### Теги форматирования (HTML-подобные)

Теги для выделения текста. Не требуют перевода содержимого внутри тегов.

- `<b>...</b>` — жирный шрифт
- `<i>...</i>` — наклонный шрифт (курсив)
- `<u>...</u>` — подчёркнутый
- `<s>...</s>` — зачёркнутый
- `<size=...>...</size>` — размер шрифта
- `<color=...>...</color>` — цвет текста
- `<mark=...>...</mark>` — выделение (маркер)
- `<align=...>...</align>` — выравнивание
- `<think>...</think>` — мысли персонажа (отображаются особым образом)

#### Оператор `|` (ИЛИ)

Символ `|` внутри текста означает, что игра случайно выбирает один из вариантов. Всё, что разделено `|`, — альтернативные варианты одной фразы.

Пример: `Hello | Hi | Hey there`

### Ошибки в строках (подсвечиваются)

- **Двойные пробелы** — два и более пробела подряд в середине строки
- **Концевые пробелы** — пробелы в конце строки
- **Концевой перевод строки** — пустая строка в конце файла
- **Em dash (U+2014 `—`)** — игра не распознаёт этот символ
- **Лишний текст в строке-заголовке** — если после `[NAME]` есть ещё символы
- **Лишний текст в строке-разделителе** — если после `----` есть ещё символы

## Подсветка синтаксиса (Monaco Editor)

Редактор использует Monaco Editor (`@monaco-editor/react`). Подсветка реализована через:

- **Monarch-токенайзер** — регистрирует язык `gamescript` с токенами: `separator`, `bracket-label`, `curly-tag`, `angle-tag`, `double-space`, `invalid-char`
- **Тема** `gamescript-theme` — цвета соответствуют CSS-классам
- **Маркеры** — двойные пробелы и концевые пробелы помечаются как `MarkerSeverity.Error`
- **Spell check** — в `TranslationEditor` неизвестные слова помечаются как `MarkerSeverity.Warning` (через nspell/Hunspell)

## Маршруты

- `/` — главное меню (Quests, Settings)
- `/quests` — список квестов с прогрессом
- `/editor/[quest]` — редактор квеста (split-view + навигация prev/next)
- `/settings` — настройки

## API Endpoints

### Файлы

- `GET /api/files` — список файлов (с пагинацией)
- `GET /api/files/[name]/orig` — оригинал
- `GET /api/files/[name]/trans` — перевод
- `POST /api/files/[name]/save` — сохранить перевод
- `POST /api/reindex` — переиндексация

### Квесты

- `GET /api/quests` — список квестов (группировка по character.section.quest)
- `GET /api/quests/[name]/files` — файлы квеста

### Настройки

- `GET /api/settings` — получить настройки + дефолты из .env
- `POST /api/settings` `{ action: "save", key, value }` — сохранить настройку
- `POST /api/settings` `{ action: "reset", key }` — сбросить на дефолт

Ключи настроек: `ORIGINALS_DIR`, `TRANSLATIONS_DIR`, `OPENROUTER_API_KEY`

## Хранилище настроек

Настройки хранятся в SQLite (таблица `settings`). Механизм:

- `getSetting(key)` — читает из БД, если нет — берёт из `import.meta.env`
- `setSetting(key, value)` — сохраняет в БД
- `resetSetting(key)` — удаляет из БД (возвращается к .env)
- `getAllSettings()` — все настройки с дефолтами

При изменении настроек путей нужно делать реиндексацию через `/api/reindex`.

## Запуск

- `npm run dev` — dev-сервер
- `npm run build` — продакшн-билд
- `POST /api/reindex` — индексация файлов
